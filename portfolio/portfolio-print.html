工作台界面：金价走势与次日预测、模型信号、驱动因子贡献分解、置信度分层命中率

做了什么

  1. 数据工程——打通 16+ 个免费、无需 API Key 的数据源：新浪财经国际期货接口提供 COMEX 黄金日线，FRED 提供实际利率、美元指数、VIX、通胀预期等宏观因子。
  2. 因子体系——构建 20 个因子，分利率、汇率、风险、通胀商品、动量五类；只用因子的「变化量」而非绝对水平做趋势外推，避免非平稳序列的伪回归。
  3. 严谨验证——走前式回测 1784 个交易日（每月滚动重训，2019-10-23 至今），严格按真实发布滞后对齐因子，杜绝未来数据泄露。
  4. 交付工程——单文件 HTML 工作台，图表库与数据全部内联，断网可打开；定时任务每日自动更新。

关键选择，以及背后的取舍

  • 不用 LSTM / 深度学习。开源社区同类项目实测：有限样本上堆外部因子 + LSTM 会严重过拟合，反而跑不过朴素基准。选择可解释性更好的强正则线性模型。
  • 用实验决定，不靠直觉。测试过滚动标准化（更差）与 GBDT（仅高 0.9pp，在噪声范围内）。最终选择线性模型，换取「因子贡献可直接相加归因」的可解释性。

做了什么

  1. 心情推荐引擎——10 种心情多选（开心/疲惫/低落/约会/熬夜/解腻/省钱/轻负担…），每种心情映射「品类 × 口味标签 × 品牌画像」三路打分，推荐语自动归因。
  2. 双模式输入——还支持口味偏好（6 大类 × 8 种茶底 × 补充条件）与品牌范围圈定，左侧边栏与主页品牌多选双向同步。
  3. 菜单数据工程——数据与逻辑分离（menu-data.js + update.json 合并）；每周一自动联网核对新品/下架并推送上线，NEW 标 3 个月自动摘除。
  4. 交付形态——零依赖单文件应用，手机全屏、桌面手机壳居中；GitHub Pages 公开托管，访客免登录直接打开。

关键选择，以及背后的取舍

  • 不接品牌方 API。点餐小程序无公开接口，选择「本地快照 + 每周联网核对」，页面明确提示数据时效。
  • 规则打分，不上模型。402 个 SKU 的推荐排序用可解释的规则加权即可，每条推荐都能给出归因文案；引入排序模型对这个规模是负收益。
  • 真交互验证，不只看截图。装不上 puppeteer 就用 Node 22 全局 WebSocket 直连 CDP 零依赖驱动系统 Chrome：点心情 → 圈品牌 → 断言推荐结果。
